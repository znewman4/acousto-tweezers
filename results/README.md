# Results

This folder is organised by presentation value.

## Current Folders

- `report/` - curated outputs that correspond to the main findings in the
  final report.
- `comsol_comparison/` - current COMSOL comparison outputs for standing,
  vortex and combined cases.
- `fem_standing_wave_cache/` - cached finite-element standing-wave fields used
  by the hybrid FEM-ASM workflow.
- `archive_studies/` - exploratory, superseded or debugging runs kept for
  provenance but not needed for a first presentation pass.

For report navigation, start with `report/README.md`.
