# Report Folder

This folder contains the LaTeX source used as the project description and
presentation anchor for this repository.

## Main File

- `Final_Major_Project_1_Report.tex` - final major project report source.

## Repository Alignment

The README and result indexes were written to match the report narrative:

- acoustic lens development: FZP vortex lens and C-shape hologram lens
- controllable in-plane standing waves: frequency and phase modulation
- integrated 3D model: FEM standing-wave field, ASM beam field, complex
  superposition and MPC phase-offset merging
- experimental platform: standing-wave chamber, translated lens assembly,
  lens manufacturing, cinnamon/polystyrene validation

The report references image files under `Figures/`. Those project-writing
assets are not all present in this code repository; the simulation outputs that
support the report are indexed in `results/report/README.md`.
