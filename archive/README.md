# Archive

This folder keeps material that is useful for provenance but should not be in
the presentation-facing root tree.

## Contents

- `project_history/` - old audits, project reviews, affirmation notes, root
  logs and one stray branch-command text file.
- `project_history/logs/` - superseded production and sweep logs.
- `project_history/script_backups/` - backup scripts moved out of active
  development folders.
- `project_history/comsol_compare_notes/` - old COMSOL comparison notes.
- `project_history/mesh_convergence_wrapper_empty/` - old empty top-level
  mesh-convergence wrapper, retained only so the move is reversible.
- `comsol_comparison_attempts/` - earlier COMSOL comparison attempts and debug
  investigations marked as incorrect or exploratory.
- `deliverables_snapshots/` - previous large `Deliverables/` snapshot, archived
  because the report-facing outputs now live under `results/report/`.
- `legacy_experiments/`, `redundant_docs/`, `results/`, `scripts_old/` -
  pre-existing archive material.

Use this folder when checking project history. Use `results/report/` for the
clean presentation path.
