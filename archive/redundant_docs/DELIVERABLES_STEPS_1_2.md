## 🧪 What Each Component Does

### Step 1: Particle Dynamics Validation

**Script Section**: Lines 180-340 in `run_particle_streaming_demo.py`

**Three Tests**:

1. **Gor'kov Alone**
   - Streaming: OFF
   - Expected: Particle traps (displacement < 0.5 mm)
   - Metric: `gorkov_displacement_mm`

2. **Streaming Alone**
   - Gor'kov: OFF (pure advection)
   - Expected: Particle drifts (displacement > 0.1 mm)
   - Metric: `streaming_displacement_mm`

3. **Streaming + Gor'kov Coupled**
   - Both ON
   - Expected: Intermediate behavior
   - Metric: `coupled_displacement_mm`

**Output**: `validation_results.json` with:

## 🎯 Implementation Highlights

### Physics ✓
- **Governing Equation**: $\dot{\mathbf{x}} = \mathbf{u}_s(\mathbf{x}) + \mu \mathbf{F}(\mathbf{x})$
- **Overdamped**: No inertia (Stokes drag dominates)

## 📋 Configuration Options

All parameters configurable in `ShallowDishConfig`:

**Geometry** (meters):
- `L`: Lateral size (default 0.01 = 1 cm)
- `H`: Depth (default 0.001 = 1 mm)

**Physics**:
- `frequency_hz`: Operating frequency (default 500 kHz)
- `vortex_velocity_amplitude`: Vortex amplitude (default 10 μm/s)
- `standing_velocity_amplitude`: Standing amplitude (default 1 μm/s)

**Particles**:
- `particle_radius`: Particle size (default 5 μm)
- `particle_density`: Material density (default 1050 kg/m³)

**Simulation**:
- `particle_t_max`: Integration time (default 0.01 = 10 ms)
- `particle_dt`: Time step (default 1e-5 = 10 μs)

**Mesh**:
- `elements_per_wavelength`: Resolution (default 4)

## 🔧 Troubleshooting

### Common Issues

**Q: "ModuleNotFoundError: acoustweezers"**
A: Add src to path:
```bash
export PYTHONPATH="/home/znewman4/projects/acousto-tweezers/src:$PYTHONPATH"
python scripts/run_particle_streaming_demo.py
```

**Q: "validation_passed: false"**
A: Check displacement metrics. May indicate:
- Mesh too coarse (increase `elements_per_wavelength`)
- Wrong frequency
- Streaming not computing

**Q: "VTU file won't open in ParaView"**
A: Check file size. If < 100 kB:
- Mesh might be too small
- Solver might not have converged
- Check script output for errors

**Q: "Particle CSV is empty"**
A: Check that `particles.csv` has > 1 row.
- Adjust initial position
- Increase `particle_t_max`
